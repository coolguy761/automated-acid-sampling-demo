## Branch Notes

### `main`
- Keep as the older GitHub-facing branch with the original README and UI image history.
- Avoid using this as the day-to-day sketch archive branch unless you intentionally want to merge newer Arduino work into it.

### `archive-current-state`
- Snapshot branch for the imported local project state.
- Useful as a compact archive of the current files without the cleaner reconstructed history.

### `historical-reconstruction`
- Primary working/archive branch for the Arduino and Nextion project files.
- Contains the cleaner historical commit sequence for older sketches plus the current project snapshot.
- Use this branch going forward when adding or organizing sketch history.
